# 小涵 · 微信里的 AI 妹妹（v0.3.0）

把一个大模型塞进你**自己的微信小号**，让它像真人一样跟你的好友聊天：
有个性、有记忆、会发表情包、会自己上网找东西、会发朋友圈、会主动找人说话。

> 项目名字「小涵」只是我给这个角色起的名字。人设、称呼、家庭关系全部写在 `persona.md` 里，
> 换一个人设就是另一个"人"，代码不用动。

---

## 1. 它能做什么

**聊天**
- 私聊 / 群聊都接；群里能判断该不该插话、谁在跟谁说话
- 分多条气泡发送，带打字延迟，不会一次糊一大段
- 会看表情：`😅` `[微笑]` `[旺柴]` 这类都翻译成语气再回
- 会看图：收到的图片会先念字（OCR）→ 有字就联网查 → 查不到再让视觉模型描述画面
- 会发表情包（本地 `stickers/` 里的图）和网图（按语境去 Bing 图片搜，偏好邦多利 / pjsk）
- 会自拍（AI 生成二次元图）、会画自己要的线稿
- 引用消息、拍一拍、@ 都能接；拍一拍的有一半概率拍回去
- 不懂就联网搜：先百科（百度百科 API），再 Bing（多路查询 + 结果重排），问技术/学术问题会顺手甩链接
- 会"梳理"：没看懂你的话会先复述确认，不硬猜

**记忆**
- 全量对话落 SQLite；定期让模型把长对话压成「称呼 / 身份 / 近况 / 喜好 / 雷区 / 约定 / 事件 / 原话」
- 被当场纠正会立刻记（"别叫我妹妹了，叫我小涵" → 雷区 + 称呼）
- 群聊里说到的关于某人的事，会落到那个人的档案上
- 说过的约定（"输的请奶茶"）到点自己提
- 隔天补刀：`[补:关键词]` 标签，第二天自己接一句"你昨天说的那个我后来想了下…"

**主动**
- 有人 N 天没聊会主动找（miss），早上 9 点、晚上 10 点各有一次开场
- 自己上网逛 B 站热门 / 抖音热榜 / 兴趣搜索，觉得有意思就分享
- 每天生成一条"今天的她"状态（心情、在哪、在干嘛），影响说话的松弛度
- 每天最多发一条朋友圈（文字 + 图）
- 白名单控制：只有 `contacts.proactive_enabled=1` 的人才会被主动找

**安全边界（可改）**
- 不点陌生链接、不开文件、不下载、不扫码 —— 链接/文件类消息在入口就被改写成 `[链接]（她没点开，也没下载）`
- 不视频、不语音通话、不收发红包
- 不给盗版 / 磁力 / 翻墙工具
- 不报真实姓名、学校、专业，被追问就打岔

## 2. 两种接微信的方式

| 方式 | 微信版本 | 原理 | 状态 |
|---|---|---|---|
| `--wx4`（推荐） | 4.1.x | 读本地数据库收消息（只读）+ 界面自动化发消息 | ✅ 在用 |
| `--uia` / `--wcf` | 3.9.x | UIA 读界面 / WeChatFerry 注入 DLL | ⚠️ 已弃用，仅留档 |
| `--mock` | 不需要微信 | 终端里跟它打字 | ✅ 调试用 |

> 为什么弃用 3.9：腾讯已禁止 3.9 系列 64 位登录，32 位还能登但要兼容层绕过；
> 更关键的是 WeChatFerry 的收消息通道在新版 spy 上不再监听 10087，收不到消息。
> 详见文末「走过的弯路」。

## 3. 环境要求

- **Windows 10 / 11**（界面自动化依赖 Win32 API）
- **Python 3.11+**（在 3.14 上跑通）
- **微信 4.1.x**（本项目在 4.1.15 上验证；4.0.3+ 才有发朋友圈）
- 一个**你自己实名、注册满 5 年的小号**（重要，见第 9 节）

依赖：

```bat
pip install wechatauto-replica uiautomation pillow pynng psutil pywin32
pip install edge-tts          :: 可选，语音合成
```

> `wechatauto-replica` 是社区做的 wxauto 4.x 复刻（GitHub: fanyuantaier/wechatauto-replica），
> 它负责「连上微信、读写消息、切朋友圈」。如果装的时候解析依赖卡住，
> 可以 `pip install wechatauto-replica --no-deps` 再逐个补上面那些。

## 4. 三步跑起来

**① 填 API Key**

复制 `keys.example.json` 为 `keys.json`，填上自己的 key：

```json
{
  "deepseek_api_key": "sk-你的deepseek密钥",
  "siliconflow_api_key": "sk-你的硅基流动密钥"
}
```

- `deepseek_api_key`：**必填**，对话用（https://platform.deepseek.com）
- `siliconflow_api_key`：**可选**，识图（Qwen3-VL）+ 生图（Qwen-Image）用（https://siliconflow.cn）

也可以用环境变量 `DEEPSEEK_API_KEY` / `SILICONFLOW_API_KEY`，环境变量优先级更高。

**② 填机器路径**

`config.json` 里的 `client` 段是给 `tools/toggle.ps1` 和开机自启用的：

```json
"client": {
  "python": "C:\\Python311\\pythonw.exe",
  "exe": "C:\\Program Files\\Tencent\\Weixin\\Weixin.exe",
  "process": "Weixin"
}
```

不填也能跑，只是快捷开关找不到路径（脚本会退回 PATH 里的 `pythonw.exe`）。

**③ 启动**

```bat
:: 先在终端里跟它聊两句，确认大脑没问题（不需要微信）
run.bat
:: 或
python -m app.main --mock

:: 接微信（微信先登录好）
python -m app.main --wx4
```

看到这几行就成功了：

```
表情包已加载：155 张
连接微信 4.x（收消息读库，发消息走界面）…
我是：小涵（wxid_xxxxxxxx）
已上线：wx4
管理页：http://127.0.0.1:8799/?token=……
调度器已启动（主动消息）
```

然后**用手机给她发一句话**试试。日志里的管理页地址带 token，用浏览器打开那一行，不要自己拼一个不带 token 的地址。

> 注意：**不要用她自己的号给文件传输助手发消息测试** ——
> 自己发的消息会被 `self_wxid` 过滤掉，看起来像"不回"。

## 5. 管理页

启动日志里有一行带 token 的地址，用浏览器打开它：

```
管理页：http://127.0.0.1:8799/?token=……
```

打开一次之后浏览器会记住（HttpOnly cookie），之后可以直接访问 http://127.0.0.1:8799 。token 写在 `data/admin.token`，这个目录本来就不进 git。不要把带 token 的地址发给别人。

管理页**只监听 127.0.0.1**。`config.json` 里把 `admin.host` 写成 `0.0.0.0` 也不会对外监听。

- **人设**：直接编辑 `persona.md`，保存后**下一句话就生效**（按文件 mtime 热加载，不用重启）
- **好友**：看每个人建档情况、关系、备注、能不能主动找他。每日主动填 `0` 就是今天不主动找
- **试聊**：不经过微信，直接在网页里跟它对话
- **日志**：最近的动作

人设改动只影响"说话的内容"；改 `.py` 代码要重启进程。

## 6. 人设怎么写

`persona.md` 是纯 Markdown，分节写成"她是谁"。当前这份包含：

年龄生日、学校、家庭（爸妈奶奶姐姐）、三只猫、和哥的关系与底细、
说话方式、对陌生人的语气、被骂时怎么还嘴、梗库、火影手游、钢四、经济外汇、
外貌与自拍、拍照画画的标签约定、禁忌与安全边界。

**约定好的标签**（模型输出里出现就会被执行）：

| 标签 | 作用 |
|---|---|
| `\|\|\|` | 分条发送（一句一个气泡） |
| `SKIP` | 这一轮不回 |
| `[表情:叹气]` | 发本地表情包 |
| `[自拍:便利店门口]` | 生成一张她的自拍发出去 |
| `[画:趴在桌上睡着]` | 生成一张她画的线稿 |
| `[找图:无语 表情包]` | 联网找一张图发出去 |
| `[搜:卡尔曼滤波]` | 联网搜索后再回答 |
| `资源:[stable diffusion 本地部署]` | 去 GitHub / 官网找项目链接 |
| `[补:输的请奶茶]` | 记下来，第二天自己提 |

所以**改人设时别乱删这些规则**，模型会照着做。

## 8. 常用脚本

```bat
:: 离线自检（不需要微信，不需要 key 也能跑一部分）
python tests/smoke.py

:: 补答某个人没被回复的那句话（超过 6 小时就拒绝硬接，免得像诈尸）
python tools/catchup.py 王洪涛 --minutes 120

:: 手动发个本地表情包
python tools/send_sticker.py 哥哥 叹气

:: 手动发一条朋友圈（--dry 只到编辑框不发表）
python tools/post_moment.py --image stickers\png\Mygo__探头.png --text "今天也在偷偷画画"

:: 看某人记了什么
python tools/show_memory.py 哥哥
```

一键开关（做快捷方式时用这个命令，图标随便挑）：

```
powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File tools\toggle.ps1
```

开机自启：把 `start_xiaohan.vbs` 里的两个路径改好，丢进 `shell:startup`。

## 9. 关于封号（务必先看）

这套方案是"一台电脑上跑一个真实的微信客户端 + 模拟操作"，**不是协议号**，行为特征比协议号安全，但：

1. **用老号**（注册满 5 年、绑手机、实名是你本人），新号一天就封
2. **别主动加人**，只跟已经是好友的人说话（`features.allow_add_friend` 默认关）
3. **别群发、别刷屏**：`config.json` 里 `limits` 全是给这个用的
4. **不要 24 小时狂发**：主动消息有窗口（9–23 点）、有次数上限
5. 被限制过就停几天，别硬顶

风险自己承担。真要长期跑，建议单独一台机器 / 一个虚拟机。

## 10. 已知限制 / 未完成

| 功能 | 状态 | 原因 |
|---|---|---|
| 朋友圈**点赞/评论** | ❌ | 4.1.15 的「…」按钮是自绘控件，不响应合成鼠标事件（试过 8 种点法，只有一次偶然开出菜单）。`app/engage.py` 留着，未启用 |
| 朋友圈**发表** | ✅ | 状态机 + 重试，能真的发出去 |
| **语音条** | ❌ | 微信 4.1 的语音必须走麦克风采集，要发合成音频得装 VB-Cable 虚拟声卡 |
| 原图清晰度 | ⚠️ | 收图只解密 mid/thumb 档；原图需要 AES 密钥（得先在微信里手动点开一张大图） |
| 群聊"看到全部" | ⚠️ | 只回它"在场"的会话；非常久没人说话的群不会自己回去翻 |
| 跨设备 | ❌ | 同一账号两个 PC 端会互踢，只能一台 |

## 11. 走过的弯路（省你几天）

1. **3.9 全线不通**：腾讯封了 3.9 的 64 位登录；32 位能靠 `__COMPAT_LAYER=~ ARM64WOWONAMD64` 进，但 WeChatFerry 39.6 的 spy 只开 10086 命令口、10087 消息口永不监听 → 收不到消息。
2. **别按窗口标题找微信**：本机编辑器标题里带"微信"两个字，库会认错进程，点击全落空。要按 `进程名 Weixin.exe + 类名 Qt5151*` 找。
3. **别用 PrintWindow 判断弹窗**：分层窗口会被渲染成纯黑，看着像"菜单没开"。判断界面状态要用屏幕像素。
4. **`SendMsg(text, who="某人")` 会静默降级**：微信里没这个人时它会发到当前会话去（踩过，把给爸爸的消息发进了文件传输助手）。要么先 `ChatWith` 再发，要么发之前核对会话名。
5. **PowerShell 脚本要存成 UTF-8 with BOM**：否则 5.1 按 ANSI 读中文注释，报 `The string is missing the terminator`。
6. **生图别硬调颜色**：Kolors 老把"蓝黑瞳"画成亮蓝、把"地雷系"画成白衬衫；换 Qwen-Image + 中文提示词才稳。
